# Контракт JSON-выгрузки каталога (для экспортёра)

Формат для загрузки товаров в GrosterHit через **«Товарные рекомендации → Импорт из
файла (XML/JSON)»** (эндпоинт `POST /admin/import-json`, парсер `app/import_json.py`).

Файл — **плоский JSON-массив** объектов-товаров. UTF-8 (BOM допускается). Лимит 50 МБ.

## Поля товара

| Поле | Тип | Обяз. | Идёт в БД | Примечание |
|------|-----|:---:|:---:|-----------|
| `product_id` | string | **да** | да | Артикул, первичный ключ. Дубли схлопываются (upsert). |
| `category_id` | string | **да** | да | Обязателен, иначе товар отклоняется. |
| `category_name` | string | да | да (в `categories.name`) | Человекочитаемое имя категории. |
| `name` | string | да | да | Название товара. |
| `price` | number | да | да | Число (int/float), не строка. |
| `in_stock` | bool | да | да | `true/false` — только `true` попадёт в топ-5/письма. |
| `image_url` | string | да | да | **См. ниже — сейчас главная проблема.** |
| `product_url` | string | нет | да | Ссылка на карточку. Пусто — допустимо. |
| `unit`,`currency`,`min_order_qty`,`stock_level`,`attributes`,`tags`,`updated_at` | — | нет | **нет** | Игнорируются импортом. |

Топ-5 и подписчиков этот формат **не содержит** (только товары). Топ-5 GrosterHit
вычисляет сам из истории заказов — кнопка «Пересчитать топ-5».

## ❗ `image_url` — что исправить

**Сейчас (неверно):** выгрузка кладёт синтезированный Bitrix-путь
```
https://groster.me/upload/iblock/<product_id>.jpg
```
Такого файла **не существует** — все ссылки отдают 404, фото не грузятся.

**Как надо:** реальный URL картинки, тот же, что использует сайт (поле `og:image` /
картинка товара в CMS). Реальные файлы лежат на **другом хосте и пути**, имя — **GUID**
(не артикул), расширение чаще `.png`:
```
https://static.groster.me/images/shop/<GUID-картинки-товара>.png
```
Проверено: такой URL отдаёт `200 image/png`. GUID берётся из БД/CMS магазина (там, где
хранится картинка), а **не выводится из `product_id`** — связи между ними нет, поэтому
починить на стороне импорта невозможно. Нужно исправить именно в выгрузке.

Если у товара нет картинки — оставьте `image_url` пустым (`""`); импорт покажет
плейсхолдер «нет фото» вместо битой иконки.

## Правильный пример

```json
[
  {
    "product_id": "00000140229",
    "name": "Тряпка/салфетка микрофибра 30*30 см, 180г/м2 ГОРНИЦА",
    "category_id": "00000000102",
    "category_name": "Тряпки, салфетки, губки, терки",
    "price": 180,
    "in_stock": true,
    "image_url": "https://static.groster.me/images/shop/edd52780-6960-11f1-92e9-74563c4adfb9.png",
    "product_url": "https://groster.me/product/tryapka-salfetka-mikrofibra-30-30-sm-180g-m2-gornica"
  }
]
```

После исправления `image_url` в выгрузке менять в GrosterHit ничего не нужно — повторный
импорт того же файла подхватит правильные ссылки, и фото появятся в каталоге и письмах.
